## It's been a while, let's get reacquainted with `vim`
- Plugins: `,pi` install, `,pu` update, `,pc` clean
- Config: `less ~/.config/vim/vimrc`
- Files: `-` opens the current folder (vinegar), `-` again goes up
- Fuzzy: `,f` files, `,b` buffers, `,w` windows, `,hs` command history
- Search: `,rg PATTERN` (fuzzy), or `:grep PATTERN` into the quickfix list
- Comments: `gcc` line, `gc{motion}`
- Surround: `cs"'` change, `ds(` delete, `ysiw]` add
- Format JSON/YAML/XML and trim whitespace: `,fmt`
- Shell: `:!COMMAND`, `:terminal`
- Key Notation: `:help key-notation`
